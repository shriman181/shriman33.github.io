Founder

Somebody has to assemble the list.

Stellrix began with a question that should have had an easy answer and didn't: when one supplier holds up a program, who else in the country could build the part? There is no list. There has never been a list — not because the data is missing, but because nobody has assembled fifty state permit registries, certification records, machine tool imports and auction filings into a single map of what industry can do.

We are building that map, and the metric that goes with it. Qualification Distance turns an unanswerable strategic question — can we second-source this? — into an operational one: here are fourteen shops within nine months of qualified, ranked by cost, capacity and risk. If you have a part with exactly one supplier, that is the conversation I want to have.

Capacity is not missing. It is unlisted.

Trust & data

Controlled data is a gate in this sector, not a footnote.

The capability graph is built entirely from unclassified, public, commercially available records, so it carries no export-controlled content by construction. Where a technical data package is genuinely required, it is handled in a segregated environment with US person access controls — and wherever possible the product works from requirement abstractions instead, so controlled material never needs to be ingested at all.
